FOLDER TEMPLATES — FORMULIR PDF SuDesApp
=======================================

Folder ini menyimpan formulir PDF milik desa. Setiap berkas .pdf yang
diletakkan di sini otomatis muncul di menu FORMULIR pada aplikasi.

Cara memakai
------------
1. Buka menu Pengaturan Formulir (atau menu Formulir -> Tambah Template).
2. Tambah berkas PDF dari komputer, atau salin langsung ke folder ini.
3. Nama berkas menjadi nama formulir di menu, jadi beri nama yang rapi
   (mis. "Surat Keterangan Domisili.pdf").
4. Klik formulir di menu untuk membuka pratinjau dan mencetaknya.

Catatan penting
---------------
- Folder ini MILIK DESA. Upgrade aplikasi tidak menimpa atau menghapus
  berkas yang sudah ada di sini.
- Berkas contoh bawaan hanya disalin saat folder ini belum berisi berkas
  tersebut; setelah itu perubahan Anda dipertahankan.
- Formulir juga bisa dicadangkan ke Google Drive lewat halaman
  Pengaturan Formulir setelah akun Google terhubung.
- Berkas selain .pdf boleh disimpan di sini, tetapi tidak ditampilkan
  sebagai formulir.
